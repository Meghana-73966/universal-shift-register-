Universal Shift Register using Verilog

Description

A Universal Shift Register is a sequential circuit that can perform multiple operations such as shift left, shift right, parallel load, and hold.
 Operations

Select| Operation
"00"| Hold
"01"| Shift Right
"10"| Shift Left
"11"| Parallel Load

Tools Used

- Verilog HDL
- Icarus Verilog
- GTKWave
- GitHub

Files

- "universal_shift_register.v" – Main Verilog design
- "universal_shift_register_tb.v" – Testbench
- "simulation/waveform.png" – Simulation waveform

 Applications

- Data storage
- Data transfer
- Serial-to-parallel conversion
- Parallel-to-serial conversion
- Digital communication systems

Expected Result

The register performs hold, right shift, left shift, and parallel-load operations according to the select inputs.
